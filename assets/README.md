# Dashboard image assets

Place the four approved Moreh Academy image assets in this directory using these exact names:

- `mgic-logo.png` — MGIC institutional logo
- `moreh-academy-logo.png` — Moreh Academy logo
- `moreh-college-logo.png` — Moreh College logo
- `moreh-academy-building.jpg` — building photograph for the dashboard side panel

## Display guidance

- Keep each logo's transparent background and original aspect ratio. Do not stretch or crop the marks.
- Display the three logos together in the dashboard's institutional banner, with consistent visual height.
- Use the building photograph in the side panel with `object-fit: cover` and a responsive portrait crop.
- Keep meaningful alt text on all images.
- The dashboard must remain usable if an image fails to load; image assets are decorative branding, not required data.
